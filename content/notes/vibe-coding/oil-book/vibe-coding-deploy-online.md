自己电脑上能打开的网站，发给别人时还需要一个可访问的地址。像这个 Hugo 博客，可以先构建静态文件，再交给 GitHub Pages 托管。

## 一次上线检查三个结果

本地先跑 `npm ci`，再跑 `hugo --gc --minify`。提交经过人工合并后，看 Actions 里的构建和发布任务。最后用线上地址打开首页，再点进一篇深层文章。

首页成功后，特别检查深层页的图和样式。路径拼错时，首页可能看起来正常，换一页才暴露问题。
