一页书签可以写在一个 HTML 文件里。等收藏和随笔两个页面都有同样的导航，你就有了第一个值得提取的组件。把它改一次，两页一起生效。

## 看数据去哪儿

只在页面上筛选标题，浏览器就能做。要让用户换设备后还能看到自己的收藏，需要把数据持久保存。调用模型时，服务端负责保管密钥，浏览器接收可以显示的结果。

自己画一条线，从点击「生成」到看到文字。标出请求内容、保存位置和错误提示。画完再看代码，前端、后端和 API 各管什么会清楚很多。
