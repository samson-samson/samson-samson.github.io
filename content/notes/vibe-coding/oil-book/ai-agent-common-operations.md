## 把需求放进可以验收的项目

Agent 能读写文件和执行命令。开工时给它独立目录，说明改动范围、参考文件和完成条件。用 Markdown 记录需求与交接，用可运行页面交付原型。换会话时，把项目路径、现状和实际跑过的命令交给下一位执行者。

## 本地练习

在空目录做一页书签列表。先确认 Agent 的计划，之后留下启动命令和验收结果。在新会话里仅提供这份交接，检查是否能继续添加一个书签分类。
