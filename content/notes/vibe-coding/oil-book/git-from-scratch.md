## 把一次完整的改动留在一个提交里

本地提交保存可追溯的状态，远程仓库让多人共享记录。分支隔离当前任务，PR 集中展示差异、验收和评审结果。让 Agent 操作 Git 前，先确认当前分支和将要提交的文件范围。

## 本地练习

在试验仓库分三次提交改一篇笔记，查看每次差异，然后让新的回退提交撤销其中一步。提交练习成果前，检查环境文件、截图和文档是否夹带私密内容。
